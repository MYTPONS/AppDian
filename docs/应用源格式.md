# 应用大典 · 应用源格式说明

应用大典的核心理念仿照 legado（阅读）的书源机制：
**应用源（AppSource）** 是一个 JSON 规则文件，它描述"如何从某个网站解析出应用列表、应用详情和下载地址"。
用户添加源 → 应用按源里的规则抓取并解析 → 统一的发现 / 搜索 / 详情体验。

- 一个源 = 一个 JSON 文件，可直接编辑、导入、导出、分享
- 内置 3 个演示源见 `app/src/main/assets/app_sources/`
- 规则引擎实现见 `engine/src/main/kotlin/com/appdian/engine/`

---

## 1. 源结构总览

```jsonc
{
  "sourceName": "示例源",                    // 必填，唯一标识
  "sourceUrl": "https://example.com",       // 必填，根地址，用于拼接相对 URL
  "sourceVersion": "1.0.0",                 // 可选，源版本号
  "sourceIcon": "https://.../icon.png",     // 可选，源图标
  "userAgent": "Mozilla/5.0 ...",           // 可选，请求 UA
  "headers": { "Referer": "https://..." },  // 可选，附加请求头

  "search": { ... },                        // 可选：搜索区块
  "detail": { ... },                        // 可选：详情区块
  "discovery": [                            // 可选：发现（首页）栏目，可多个
    { "title": "热门应用", "section": { ... } }
  ]
}
```

search / detail / discovery 至少要有其中一个，否则导入会失败。

## 2. 区块（AppSection）结构

```jsonc
{
  "url": "/search?q={{key}}",        // 必填，请求地址（模板，相对地址自动拼 sourceUrl）
  "method": "GET",                    // 可选：GET / POST
  "body": "keyword={{key}}",          // 可选：POST 请求体
  "headers": { "X-Api-Key": "..." },  // 可选：本节附加请求头
  "type": "AUTO",                     // 可选：AUTO(自动探测) / HTML / JSON
  "listRule": "json:$.packages",      // 列表容器规则：从文档中挑出全部"条目"
  "itemRules": {                      // 每个条目的字段提取规则
    "name": "json:name",
    "icon": "json:icon => {{sourceUrl}}/repo/{{this}}",
    "version": "json:$.packages[0].versionName",
    "packageName": "json:packageName",
    "summary": "json:summary",
    "detailUrl": "{{sourceUrl}}/api/v1/packages/{{packageName}}",
    "description": "json:$.description",
    "downloadUrl": "json:browser_download_url",
    "downloadName": "json:name",
    "downloadSize": "json:size",
    "lastUpdate": "regex:([0-9]+)",
    "developer": "css:.author@text"
  }
}
```

### 字段说明

| 字段 | 含义 |
|---|---|
| name | 应用名（列表页必须能提取到） |
| icon | 图标 URL |
| version | 版本号 |
| packageName | 包名（如 com.termux） |
| summary | 一句话简介（列表页显示） |
| detailUrl | 详情页地址模板，可引用 `{{packageName}}` 等已提取字段 |
| description | 详细介绍（详情页） |
| downloadUrl | APK 下载地址 |
| downloadName | 下载文件名 |
| downloadSize | 文件大小（原始值或"45.6 MB"） |
| lastUpdate / developer | 元信息（详情页展示） |
| extras | 额外中间变量（任意 `{{var}}` 规则，供其它字段和详情 URL 引用） |

## 3. 规则语法（规则引擎）

每条规则是一个字符串，支持多规则回退：`规则A || 规则B || 规则C`，取第一个非空结果。

### 3.1 选择器类型

| 前缀 | 说明 | 示例 |
|---|---|---|
| `css:` | Jsoup CSS 选择器，作用于 HTML | `css:div.app-item` |
| `json:` | JSON 路径，作用于 JSON 响应 | `json:$.packages[0].apkName` |
| `regex:` | 正则提取，作用于元素文本/JSON 值 | `regex:版本[：:]\\s*([0-9.]+)` |
| `text:` | 纯文本（可含模板变量） | `text:https://.../favicon.svg` |
| （无前缀） | 模板字符串 | `{{sourceUrl}}/api/v1/packages/{{packageName}}` |

### 3.2 属性提取后缀

作用于 css 规则，`@` 后跟：

| 后缀 | 含义 |
|---|---|
| `@text` | 元素文本（默认） |
| `@html` | 元素内部 HTML |
| `@ownText` | 只取自身的直接文本 |
| `@attr:href` | 取指定属性值 |
| `@allAttr` | 输出全部属性 |
| `@N` | regex 专属：取第 N 个捕获组（默认取第 1 组，无组则取整个匹配） |

示例：`css:a.download@attr:href`、`css:img.cover@attr:src`、`css:.desc@html`

### 3.3 JSON 路径子集

- `$` 根节点；`$.a.b` 键访问；`[0]` 下标；`[*]` 全部元素
- 列表条目上下文内可用相对路径：`json:name`（等价于 `json:$.name`）
- `json:$.*` 取对象全部值

### 3.4 模板变量 `{{变量}}`

在 URL、请求体、规则文本中展开：

| 变量 | 来源 |
|---|---|
| `{{key}}` | 搜索关键词 |
| `{{sourceUrl}}` / `{{sourceName}}` | 源配置 |
| `{{detailUrl}}` | 列表条目提取出的详情地址（详情区块 URL 用） |
| `{{packageName}}` `{{name}}` `{{version}}` 等 | 已提取出的条目字段（按依赖顺序：packageName → name → version → summary → lastUpdate → developer → downloadName → icon → detailUrl → description → downloadUrl → downloadSize） |

### 3.5 转换模板 `=>`

把提取出的原始值交给模板加工，`{{this}}` 指向原始值：

```
"icon": "json:icon => {{sourceUrl}}/repo/{{this}}"
"downloadUrl": "json:$.assets[0].browser_download_url => https://cdn.mirror.example/{{this}}"
```

### 3.6 URL 自动补全

以 `http(s)://` 开头的保留原样；`//x` 补为 `https://x`；`/x` 补为 `源根地址/x`；其余补为 `源根地址 + "/" + 值`。

### 3.7 提取结果管道：`=> regex:...`

把提取结果再做一次正则加工（有捕获组取第 1 组，否则取整个匹配）：
常用于「CSS 取到属性值 → 再抠出 URL/版本号」：

```
css:a.qrcode_show@attr:onclick => regex:https://[^`]+\.apk[^`]*   # 从 onclick 里抠 APK 直链
css:h1@text => regex:^(.+?)\s+[\d.]+$                            # 从"名字 版本号"里抠名字
regex:大小[：:]\s*(.+)                                              # 去掉"软件大小："前缀
```

管道可与 `||` 回退链组合（每个回退分支各自带管道）：
`css:h1@text => regex:^(.+?)\s+[\d.]+$ || css:h1@text` —— 抠名字失败则退回整段 h1 文本。

### 3.8 extras：任意中间变量

```jsonc
"itemRules": {
  "name": "json:full_name",
  "detailUrl": "{{sourceUrl}}/repos/{{full_name}}/releases/latest",  // 引用 extras
  "extras": { "full_name": "json:full_name" }
}
```

extras 中提取的变量会进入条目上下文，可在其它字段模板、以及**详情区块的 URL 模板**（通过条目的 `vars` 透传）中继续引用。

## 4. HTML 源示例

```jsonc
{
  "sourceName": "某应用站",
  "sourceUrl": "https://apps.example.com",
  "search": {
    "url": "/search?keyword={{key}}",
    "listRule": "css:ul.app-list > li",
    "itemRules": {
      "name": "css:.title@text",
      "icon": "css:img@attr:src",
      "version": "css:.ver@text || regex:V([0-9.]+)",
      "detailUrl": "css:a@attr:href"
    }
  },
  "detail": {
    "url": "{{detailUrl}}",
    "itemRules": {
      "name": "css:h1@text",
      "icon": "css:img.cover@attr:src",
      "description": "css:.desc@text",
      "downloadUrl": "css:a.btn-download@attr:href",
      "downloadSize": "regex:([0-9.]+\\s*MB)"
    }
  },
  "discovery": [
    { "title": "本周热门", "section": { "url": "/top", "listRule": "css:li.app", "itemRules": { "name": "css:.title@text", "detailUrl": "css:a@attr:href" } } }
  ]
}
```

## 6. 已知约定 / 注意事项

1. 列表解析时，`listRule` 命中的每个节点就是"一个条目"的上下文，条目内规则自动作用于该节点
2. 多元素命中：字符串类规则会对多个匹配结果用 `\n` 拼接（写源时尽量把选择器写精确）
3. 类型不匹配的规则返回空并走 `||` 下一条（例如 HTML 页面上的 `json:` 规则）
4. 抓取失败、解析失败不影响其它源/栏目，页面会就地显示错误
5. 源文件只允许出现在 `filesDir/sources/`，导入时校验 sourceName/sourceUrl/区块完整性

## 7. 引擎模块可测性

`:engine` 是纯 Kotlin 模块（无 Android 依赖），规则引擎、JSONPath、模板、SourceParser
均有 JVM 单元测试；`:app` 的集成测试用 MockWebServer 验证「抓取→解析」全链路。
新增规则类型时请同步补测试。
